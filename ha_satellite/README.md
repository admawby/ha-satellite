# Home Assistant Add-on: HA Satellite

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Launch satellites of your Home Assistant instance on remote Raspberry Pis (and Synology NAS units).

- Share USB Z-Wave / Zigbee / Thread sticks over the network (Z-Wave JS, Zigbee2MQTT, ZHA)
- CPU temperature, load, memory, disk, under-voltage and throttling as HA entities
- Web terminal and command runner for each Pi
- Scheduled, automatic `apt` upgrades with optional reboot
- Reboot, shutdown, service control and journal viewer
- Mutual-TLS with a private CA, one-time enrollment tokens and a LAN-only firewall

See the **Documentation** tab for setup and the security model.
